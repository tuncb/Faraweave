# Faraweave 0.2.0

Faraweave 0.2.0 expands the language while simplifying its execution model. The release ships first-class UTF-8 strings, immutable bindings, stable vector filtering, connected-application completion and placeholders, typed-empty trivia, and canonical or raw value formatting through `format` and `printf`.

Reliability work unifies recoverable `run`/`run-ir` allocation failures, preserves wrapped error sources, updates CI to the approved Node 24 checkout action, and consolidates conformance support. The C emitter and native compiler path have been removed; the verified Rust interpreter is now the sole execution backend.

See [CHANGELOG.md](https://github.com/tuncb/Faraweave/blob/v0.2.0/CHANGELOG.md) for the complete issue-by-issue list. Release assets are provided for Linux x64, Windows x64, and macOS arm64 together with `release-manifest.json` and GitHub build-provenance attestations.
