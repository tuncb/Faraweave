# Issue 8: Verified IR C generator

The internal C generator accepts only `VerifiedProgram`, preflights its execution configuration, and emits direct `fw_impl_<implementation_id>`/`fw_kernel_<implementation_id>` calls from verified stable identities. Conversions, lifting, dynamic shape checks, parameter metadata, diagnostic origins, and child-before-aggregate admission order come from IR records rather than AST or runtime type re-analysis. The legacy source generator remains the public path until issue #9, while shared strict-float, resource, formatting, and transactional runtime support is retained.
