# Issue #10 — canonical FWIR v1 encoding

FWIR v1 uses a fixed-width little-endian sectioned binary with a sorted directory, exact binary64 bits, and explicit canonical record layouts; canonical text and schema-runtime formats remain inspection or interchange alternatives rather than executable identity. Mandatory unknown features or sections and incompatible major versions are rejected, while explicitly optional advisory sections may be skipped and do not participate in the canonical program identity. Arena indexes and counts are `u32`, file offsets and lengths are `u64`, all sizing is checked before fallible allocation, and neither Rust layout nor native word size appears on the wire. Faraweave is the authoritative v1 producer, and producer/version/source-digest metadata is optional, unauthenticated, and excluded from identity.
